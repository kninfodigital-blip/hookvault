# Hook Vault V2 — Landing Page (variante Quiet Progress)

Segunda opcion de landing para **Hook Vault** con layout centrado estilo Quiet Progress: hero full-screen, proof bar, FAQ en dos columnas y terminal integrado en CTA final.

## Abrir

Doble click en `index.html` o:

```bash
python3 -m http.server 8000
```

## Stripe

Busca `PLACEHOLDER` en `index.html` (2 CTAs) y sustituye por tu link real.

## Diferencias con V1

- Hero centrado full-viewport (vs 2 columnas)
- Barra de numeros clave bajo el hero
- Feature cards con numero grande lateral
- Backed cards con stripe de color superior
- FAQ en 2 columnas (titulo sticky a la izquierda)
- CTA final con stack de valor + terminal lado a lado
- Scroll indicator animado en hero
- Animaciones con cubic-bezier mas suaves
